TUNEET 개인정보 처리방침

시행일: 2026-11-19

TUNEET 팀 (멋쟁이사자처럼 14기)(이하 "TUNEET")는 「개인정보 보호법」 등 관련 법령을 지키며, 이용자의 개인정보를 다음과 같이 처리합니다.

1. 처리하는 개인정보와 목적

구분 항목 목적 보유 기간
회원가입 (필수) 이메일, 비밀번호(암호화 저장) 회원 식별, 로그인, 계정 관리 회원 탈퇴 시까지
프로필 (필수·선택) 닉네임(필수), 프로필 사진(선택) 프로필 표시, 다른 회원과의 소통 회원 탈퇴 시까지
음악 취향 (선택) 선호 장르, 좋아하는 아티스트, 좋아하는 노래, 프로필 음악 음악 프로필 제공, 취향이 비슷한 회원 추천 회원 탈퇴 또는 해당 항목 삭제 시까지
위치정보 (선택) 기기의 현재 위치(위도·경도), 위치정보 동의 일시 주변의 취향이 비슷한 회원 추천, 회원 간 거리 구간 표시 동의 철회 또는 회원 탈퇴 시 즉시 삭제
서비스 이용 중 생성 편지, 피드 글·코멘트, 방 게시글·플레이리스트, 차단 목록, 알림 기록 서비스 기능 제공 회원 탈퇴 시까지 (아래 4항 참고)
푸시 알림 기기 알림 토큰 알림 발송 로그아웃·회원 탈퇴 시까지
자동 생성 접속 기록, 오류 기록 보안, 오류 대응 3개월

위치정보는 정확한 좌표를 다른 회원에게 보여주지 않으며, 다른 회원에게는 "1km 이내"와 같은 거리 구간만 표시합니다. 설정에서 "위치정보 노출"을 끄면 다른 회원에게 추천되지 않고, 본인도 주변 회원 추천을 받을 수 없습니다.

2. Google 사용자 데이터 (YouTube 연동)

이용자가 "유튜브 뮤직 연결하기"를 선택한 경우에만 Google 계정으로 로그인해 다음 데이터에 접근합니다. 연동은 선택이며, 연동하지 않아도 음악 취향을 직접 입력해 서비스를 이용할 수 있습니다.

접근하는 데이터 (권한: https://www.googleapis.com/auth/youtube.readonly)

  • YouTube Music에서 좋아요를 누른 곡 목록의 영상 ID, 영상 제목, 채널 이름
  • Google이 발급한 인증 토큰 (갱신 토큰은 암호화해 저장)

사용 방법

  • 좋아요 곡의 제목과 채널 이름으로 TUNEET 곡 데이터베이스의 곡을 찾아, 이용자의 "좋아요 곡"으로 저장합니다.
  • 저장한 좋아요 곡은 음악 프로필 구성, 좋아하는 아티스트 후보 제안, 취향이 비슷한 회원 추천에만 사용합니다.
  • 곡을 찾기 위해 영상 제목과 채널 이름만 TUNEET의 곡 검색 서버로 보내며, 이때 이용자 식별 정보와 인증 토큰은 보내지 않습니다.
  • 영상 ID와 곡의 연결 정보는 이용자를 식별할 수 없는 형태로 저장해 다른 회원의 연동에도 재사용합니다.

하지 않는 것

  • Google 사용자 데이터를 판매하거나 광고에 사용하지 않습니다.
  • Google 사용자 데이터를 제3자에게 제공하지 않습니다. 단, 법령에 따른 요청, 보안 목적, 서비스 양도의 경우는 Google API 서비스 사용자 데이터 정책이 허용하는 범위에서만 예외로 합니다.
  • 사람이 Google 사용자 데이터를 열람하지 않습니다. 단, 이용자의 동의를 받은 경우, 보안·악용 조사, 법령 준수, 또는 이용자를 식별할 수 없게 처리한 데이터로 내부 운영을 하는 경우는 예외로 합니다.
  • YouTube 재생 기록, 구독 목록, 이메일 등 위에 적지 않은 데이터에는 접근하지 않습니다.

보관과 삭제

  • 저장한 좋아요 곡은 최대 30일마다 YouTube에서 다시 불러와 갱신하며, YouTube에서 좋아요를 취소한 곡은 TUNEET에서도 삭제합니다. 갱신할 수 없게 되면(권한 해제 등) 저장한 좋아요 곡을 삭제합니다.
  • 설정의 "음원 플랫폼 연동"을 끄면 Google 인증 토큰을 즉시 폐기하고, YouTube에서 불러온 좋아요 곡을 즉시 삭제합니다. (YouTube 정책 기준 최대 7일)
  • Google 계정의 보안 설정에서 TUNEET 권한을 해제한 경우, 이를 확인한 뒤 30일 안에 YouTube에서 불러온 데이터를 삭제합니다.
  • Google 계정에서 TUNEET의 접근 권한은 언제든 Google 보안 설정 페이지에서 해제할 수 있습니다.

TUNEET는 YouTube API 서비스를 사용합니다. YouTube 데이터의 처리에는 Google 개인정보처리방침도 적용됩니다.

TUNEET's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
(TUNEET가 Google API로부터 받은 정보를 사용하고 다른 앱으로 전송하는 것은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.)

3. 개인정보 처리 위탁과 국외 이전

수탁자 위탁 업무 이전 국가 이전 항목
Amazon Web Services 서버 운영, 프로필 사진 저장 대한민국 (서울 리전) 1항의 전체 항목
Vercel 웹사이트 제공 미국 접속 IP, 브라우저 정보, 접속 기록
Oracle Cloud 곡 검색·곡 찾기 서버 운영 대한민국 (춘천 리전) 영상 제목, 채널 이름 (이용자 식별 정보 없음)
Google (Firebase Cloud Messaging) 푸시 알림 발송 미국 기기 알림 토큰, 알림 내용

국외 이전(Vercel, Google)은 서비스를 이용할 때 네트워크를 통해 수시로 이루어지며, 각 수탁자의 보유 기간은 위탁 계약 종료 또는 회원 탈퇴 시까지입니다. 푸시 알림은 기기 설정이나 앱 설정에서 끄면 알림 토큰이 국외로 이전되지 않습니다. 웹사이트 제공(Vercel)을 위한 이전은 서비스 이용에 꼭 필요하므로, 거부하려면 서비스 이용을 중단하거나 회원 탈퇴를 해야 합니다.

4. 개인정보의 파기

  • 회원 탈퇴 시 이메일·닉네임·프로필 사진·프로필 음악·위치정보·인증 정보를 즉시 파기하거나 식별할 수 없게 바꿉니다.
  • 다른 회원에게 보낸 편지 등은 받은 회원의 서비스 이용을 위해 남을 수 있으며, 보낸 사람은 "탈퇴한 사용자"로 표시됩니다. 탈퇴한 회원이 작성한 피드 글과 그 글의 코멘트는 함께 삭제됩니다.
  • 전자 파일은 복구할 수 없는 방법으로 삭제합니다.

5. 이용자의 권리

이용자는 언제든 자신의 개인정보 열람, 정정, 삭제, 처리 정지를 요구할 수 있습니다.

  • 앱에서 직접: 프로필 수정, 취향 수정, 위치정보 동의 철회, 위치 노출 끄기, 음원 플랫폼 연동 해제, 회원 탈퇴
  • 문의처로 요청: 아래 7항. 요청을 받은 날부터 10일 안에 처리합니다. 삭제 요청은 7일 안에 처리합니다.

6. 안전성 확보 조치

  • 비밀번호와 로그인 갱신 토큰은 해시로, Google 갱신 토큰은 암호화해 저장합니다.
  • 모든 통신은 HTTPS로 암호화합니다.
  • 개인정보에 접근할 수 있는 인원을 운영자로 제한합니다.

TUNEET는 광고·추적용 쿠키를 사용하지 않습니다. 로그인 상태를 유지하기 위해 브라우저 저장소에 인증 토큰을 저장하며, 로그아웃하면 삭제됩니다.

TUNEET는 만 14세 미만 아동의 회원가입을 받지 않습니다. 만 14세 미만으로 확인된 계정은 탈퇴 처리하고 개인정보를 파기합니다.
